# Handoff 2026-10-13: Zohara Agent plan, Zohara Link state corrected

## Owner's decisions
* **Zohara Agent is written in Rust.** The engine, the tool broker (`zohara-tools`), the gateways and the root helper are all Rust. No Python ships
  (Hermes, if a user installs it, is their own choice and not part of Zohara). `scripts/vm/vm.py` stays Python: it is dev-only and never ships.
* Opt-in layer, off by default, removable. Zohara owns the permissions; the agent only proposes. Everything goes through one broker with risk tiers
  T0 to T3, an append-only audit log and a kill switch. Other agents (Claude Code, Codex, Hermes, OpenClaw, Devin CLI) connect to the same broker
  over MCP, capped at T1 by default, never T3.
* Build order: phase 0 foundations, 1 read-only tools (no model needed), 2 permissions and undo, 3 engine + sandbox, 4 phone and voice, 5 memory and
  skills, 6 other gateways, 7 routines, 8 hardening and release. Gates A (after 3), B (after 5), C (before beta). New repo `zohara-agent`, packages
  `zohara-tools`, `zohara-agent`, `zohara-agent-skills`; alpha first through `publish-alpha.yml`; not in the ISO until the last phase.
* Defaults kept until the owner says otherwise: engine from scratch with `rmcp`; Settings flags first, shared crate only if painful; secret store
  decided in phase 0; owner is the first user; learned skills never activate without review.
* **Nothing of the agent is built yet.** This is a plan only.
