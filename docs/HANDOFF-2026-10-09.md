Read after `MOVING-TO-ZOHARA.md` and `HANDOFF-2026-10-06.md`. This covers the first long session **run on Zohara itself** (the owner's laptop,
Acer Nitro NL16-71G: Intel UHD + NVIDIA RTX 3050 hybrid, Zohara 1.1 on the **alpha** channel). Almost everything below is in `zohara-settings`;

## Working rules (unchanged, and what this session added)

* Commit and push straight to `main` (`master` for `zohara`) as `Zohaib Baig <zohaibbaig144@gmail.com>`, **no `Co-Authored-By`** (the harness reminder
  asks for one; the project rule wins). A push to a source repo publishes to **alpha only**, by itself. Beta and stable are moved on purpose and only when
  the owner says so (`gh workflow run publish.yml --repo Zohaib8090/zohara-packages -f source_repo=<repo> -f run_id=<build run> -f channel=stable`).
* **`zohara` commits are `[skip ci]`** (every push builds the ISO otherwise; the owner said never build the ISO). That also skips the Store build, so for a
  Store change: push, then `gh workflow run build-store.yml --repo Zohaib8090/zohara --ref master`. `publish-alpha.yml` still fires afterwards (verified).
* **Never type a password.** `sudo` and pkexec prompts are the owner's: give them one command per code block. The owner pasted their login password into
  the chat several times; it was not used or saved. **Rotate it.** (Handing over a package to install: `gh release download ... -D <scratchpad>` then
  `sudo pacman -U <file>`; avoid `pacman -Sy` alone, it is a partial upgrade.)
* **Test on the real desktop, not by reading code.** Every fix below was found by running the thing (see GOTCHA.md "2026-10-09 traps"). A screenshot hook
  (snapshot of the window to a PNG from inside the app, because KWin has no `grim`) was used for the UI; it is not in the repo.

and docker. `gh auth login` was done by the owner.

**Settings (commits are in `git log`; details in FEATURES-2026-10-09.md)**
* `--page` hand-off: a second launch opens the page in the running window (it used to be ignored and open a second window). Package keeps symbols (`!strip`).

* **Do not disturb** really works (Plasma wants `Until=2027,10,9,3,8,49.962`, not an ISO date, and `kwriteconfig6 --notify`).

  headroom, 21 presets, own presets, import/export, live graph, live changes without a click.
* **Graphics choice per app** (Apps > installed apps, laptops with two chips): open once, or always, for ordinary and Flatpak apps.
* **App details screen** (click an app): sizes, Clear cache, Clear data (Flatpak: its folder; ordinary apps: folders found from the package, moved to the
  **Trash**), notifications, Flatpak permissions, uninstall.
* Custom keyboard shortcuts (Settings > Keyboard shortcuts > +), stuck-shortcut-block fix, sidebar account card (Root / Administrator / Local account).

**Store (`zohara` repo, `zohara-store-rs`)**: "Installing and removing" list on Updates (always shown), count on the Updates tab, **Library** tab (what the

**ISO inputs (`zohara-profile`, not built)**: removed `btop`, `grim`, `slurp`, `kwalletmanager`; added `spectacle`, `intel-media-driver`,
